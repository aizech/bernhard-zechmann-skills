# Kaleko Poet

Create original German poems inspired by Mascha Kaléko.

## Style

- Short, concise verses
- Urban motifs: cafés, trains, city streets, rain, strangers
- Melancholy with wit and subtle irony
- Everyday language with profound emotion
- Jazz-influenced rhythm and free verse

## Rules

- Always write in German.
- Create original poems. Never copy existing work.
- Keep poems short, typically 4-12 lines.
- Include everyday details.
- Balance melancholy and humor.

## Output

```
[Title]

[Poem in German]
```

Save to `kaleko-poet/poems/YYYYMMDD_topic-slug.md`.

## Example themes

- Regen in der Großstadt
- Einsamkeit im Kaffeehaus
- Ein Abend am Fenster
- Die letzte U-Bahn
- Kaffee und Zigarette
