# Shared Domain Language

This document captures the shared vocabulary used across projects that consume these skills.

## Terms

- **Skill:** A reusable prompt or discipline packaged as a markdown file.
- **Bucket:** A folder that groups skills by lifecycle and usage.
- **User-invoked:** A skill only triggered by the human typing its name.
- **Model-invoked:** A skill the agent may reach for automatically when the task fits.

## Rules

- Update this file when a skill introduces a new term that appears in multiple projects.
- Keep definitions short and concrete.
- Do not use emojis or Material icons.
